# WORD Game

لعبة ويب كاملة لـ "WORD" باستخدام TypeScript وVite.

## المميزات
- شاشة البداية
- زر Play
- شاشة اللعبة
- لوحة مفاتيح افتراضية
- نظام نقاط
- مستويات صعوبة
- Daily Challenge
- سجل أفضل النتائج
- ألوان الحروف:
  - أخضر = حرف صحيح في المكان الصحيح
  - أصفر = حرف صحيح لكن في مكان غير صحيح
  - رمادي = حرف غير موجود

## التشغيل
1. قم بتثبيت الحزم:
   ```bash
   npm install
   ```
2. شغل التطبيق:
   ```bash
   npm run dev
   ```
3. افتح المتصفح على الرابط المعروض في الطرفية.

## البناء للإنتاج
```bash
npm run build
```

## هيكل المشروع
- `index.html` — صفحة التطبيق
- `src/main.ts` — منطق التطبيق والواجهة
- `src/game.ts` — منطق اللعبة والكلمات
- `src/style.css` — التصميم الاحترافي
